# 🎮 Hangman Game – Python

A simple text-based Hangman Game developed using Python. This project allows players to guess a randomly selected word one letter at a time. It is designed to practice basic Python programming concepts such as loops, conditions, strings, lists, and random word selection.

## 📌 Project Overview

This Hangman Game is created as part of the **CodeAlpha Python Programming Internship – Task 1**.

The game selects a word from a predefined list, hides its letters, and allows the player to guess the word. The player has a maximum of 6 incorrect guesses to complete the word.

## ✨ Features

* Random word selection from a list of 5 predefined words.
* Letter-by-letter word guessing.
* Maximum of 6 incorrect guesses.
* Displays correct and incorrect guesses.
* Prevents repeated letter guesses.
* Simple text-based console interface.
* Beginner-friendly Python implementation.

## 🛠️ Technologies Used

* **Programming Language:** Python
* **Libraries:** Random (built-in Python module)
* **Development Environment:** Visual Studio Code
* **Interface:** Command Line / Console
